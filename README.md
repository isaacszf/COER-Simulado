# Simulado - COER

Plataforma independente de estudos para a prova do **COER - Classe C** de radioamador.

## Status

MVP em desenvolvimento, com:

- modo **Simulado**;
- modo **Treino**;
- interface estática e responsiva.

## Executar localmente

```bash
cd app
npm install
npm run dev
```
